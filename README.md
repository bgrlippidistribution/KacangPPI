# SLA Alert & Exception Control Tower

Dashboard monitoring untuk impor kacang dengan fitur real-time alert dan SLA tracking.

## 🚀 Fitur

- **Ringkasan Status Alert** - Tampilan cepat semua status alert
- **Distribusi SLA** - Donut chart distribusi SLA
- **Tabel Alert Aktif** - Daftar semua alert dengan filter
- **Journey 12 Tahapan** - Visualisasi perjalanan shipment
- **Detail Tahapan** - Informasi detail per checkpoint
- **Popup Detail** - Informasi lengkap per tahapan
- **Auto Refresh** - Update data setiap 5 menit
